# jefrijunifer-website

Website profesional Jefri Junifer Pangaribuan (situs statis: HTML, CSS, JavaScript).

## Struktur
- `index.html`, `style.css`, `script.js` — halaman utama
- `publications.js` — data publikasi dari ekspor Scopus
- `assets/` — taruh foto di sini: `foto-potret.png` (foto hero)

## Memperbarui publikasi
Ekspor ulang CSV dari Scopus, lalu perbarui `publications.js`.

## Deploy
Impor repository ini di Vercel (Framework Preset: Other, tanpa build command).
